# Piso

## Descrição
Revestimento interno do piso. Classificação por grupo construtivo (Tabela II — Matriz de classificação dos padrões, referência Tipo 1). O padrão apurado (A–D) determina o Vu-C.

## Fatores / coeficientes
| Classe | Descrição | Fator |
| --- | --- | --- |
| Especial | Piso especial | A |
| Madeira maciça | Assoalho de madeira | A |
| Cerâmica | Piso cerâmico | B |
| Taco | Taco de madeira | B |
| Cimento | Cimento queimado/alisado | C |
| Caco cerâmico | Caco cerâmico | D |
| Terra | Piso em terra | D |

## Aplicação no cálculo
A característica constatada define a letra de padrão do grupo; a combinação dos grupos define o padrão global (A–D) e o Vu-C da Tabela III. Ver [[Tipo de construção]].
