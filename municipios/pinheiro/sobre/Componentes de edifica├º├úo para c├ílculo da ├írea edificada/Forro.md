# Forro

## Descrição
Tipo de forro. Classificação por grupo construtivo (Tabela II — Matriz de classificação dos padrões, referência Tipo 1). O padrão apurado (A–D) determina o Vu-C.

## Fatores / coeficientes
| Classe | Descrição | Fator |
| --- | --- | --- |
| Gesso | Forro de gesso | A |
| Madeira | Forro de madeira | A |
| Laje | Laje | B |
| PVC | Forro de PVC | C |
| Sem | Sem forro | D |

## Aplicação no cálculo
A característica constatada define a letra de padrão do grupo; a combinação dos grupos define o padrão global (A–D) e o Vu-C da Tabela III. Ver [[Tipo de construção]].
