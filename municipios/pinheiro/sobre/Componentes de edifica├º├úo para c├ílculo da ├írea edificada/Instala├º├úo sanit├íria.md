# Instalação sanitária

## Descrição
Instalação hidrossanitária. Classificação por grupo construtivo (Tabela II — Matriz de classificação dos padrões, referência Tipo 1). O padrão apurado (A–D) determina o Vu-C.

## Fatores / coeficientes
| Classe | Descrição | Fator |
| --- | --- | --- |
| Interna completa | Rede interna completa | A |
| Interna simples | Rede interna simples | B |
| Externa | Instalação externa | C |
| Sem instalação | Sem instalação | D |

## Aplicação no cálculo
A característica constatada define a letra de padrão do grupo; a combinação dos grupos define o padrão global (A–D) e o Vu-C da Tabela III. Ver [[Tipo de construção]].
