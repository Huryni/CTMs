# Cobertura

## Descrição
Tipo de cobertura. Classificação por grupo construtivo (Tabela II — Matriz de classificação dos padrões, referência Tipo 1). O padrão apurado (A–D) determina o Vu-C.

## Fatores / coeficientes
| Classe | Descrição | Fator |
| --- | --- | --- |
| Especial | Cobertura especial | A |
| Telha cerâmica (barro) | Telha de barro | B |
| Laje | Laje impermeabilizada | B |
| Telha de amianto (fibrocimento) | Fibrocimento | C |
| Palha | Palha | D |
| Cavaco | Cavaco (madeira reaproveitada) | D |

## Aplicação no cálculo
A característica constatada define a letra de padrão do grupo; a combinação dos grupos define o padrão global (A–D) e o Vu-C da Tabela III. Ver [[Tipo de construção]].
