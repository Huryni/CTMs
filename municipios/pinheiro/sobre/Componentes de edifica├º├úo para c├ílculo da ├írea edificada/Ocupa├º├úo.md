# Ocupação

## Descrição
Fator de ocupação/uso do lote (Tabela IV — Fator de ocupação do lote do CTM).

## Fatores / coeficientes
| Classe | Descrição | Fator |
| --- | --- | --- |
| Construído | Lote edificado | 1,00 |
| Não construído | Terreno sem edificação | 1,25 |
| Ruínas | Edificação em ruínas | 1,20 |
| Construção paralisada | Obra paralisada | 1,10 |
| Agropecuária | Uso agropecuário | 1,00 |
| Serviço de estacionamento | Uso como estacionamento | 1,20 |

## Aplicação no cálculo
Multiplica o valor unitário do terreno; note o acréscimo para terrenos não construídos (1,25).
