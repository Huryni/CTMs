# Estrutura

## Descrição
Sistema estrutural da edificação. Classificação por grupo construtivo (Tabela II — Matriz de classificação dos padrões, referência Tipo 1). O padrão apurado (A–D) determina o Vu-C.

## Fatores / coeficientes
| Classe | Descrição | Fator |
| --- | --- | --- |
| Metálica | Estrutura metálica | A |
| Concreto | Concreto armado | A |
| Alvenaria e metálica | Mista | B |
| Alvenaria e concreto | Mista | B |
| Alvenaria e madeira | Mista | C |
| Alvenaria | Alvenaria autoportante | C |
| Madeira | Estrutura de madeira | D |

## Aplicação no cálculo
A característica constatada define a letra de padrão do grupo; a combinação dos grupos define o padrão global (A–D) e o Vu-C da Tabela III. Ver [[Tipo de construção]].
