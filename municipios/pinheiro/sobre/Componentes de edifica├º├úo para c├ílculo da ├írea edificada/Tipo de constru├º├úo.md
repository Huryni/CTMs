# Tipo de construção

## Descrição
Tipo e padrão construtivo da edificação, que define o valor unitário de construção (Vu-C) da Tabela III — PGV do CTM.

## Fatores / coeficientes
| Tipo | Padrão | Vu-C (R$/m²) |
| --- | --- | --- |
| Tipo 1 — Residencial horizontal | A / B / C / D | 300,00 / 240,00 / 180,00 / 120,00 |
| Tipo 2 — Residencial vertical (apartamentos) | A / B / C / D | 280,00 / 220,00 / 160,00 / 100,00 |
| Tipo 3 — Comercial | A / B / C | 360,00 / 280,00 / 220,00 |
| Tipo 4 — Barracões/galpões/telheiros/postos/armazéns/depósitos | A / B / C | 280,00 / 220,00 / 160,00 |

## Aplicação no cálculo
O valor da área edificada = área construída × Vu-C do tipo/padrão. O padrão (A–D) resulta da classificação dos grupos construtivos (ver notas de Estrutura, Cobertura, Piso etc.).
